How to use these

Working the set

  1. Closed book first, key second. Every page has an Answer key switch in the top bar. Leave it off until you have written something in every box — a key read before the attempt teaches you nothing about what you actually know.
  2. Show work even when you are alone. Every MA103 rubric awards partial credit for shown work and deducts for a correct answer with none. Practicing without the work shown trains the habit that costs points.
  3. Print what you want on paper. Each page has a Print button in the top bar that lays the document out cleanly, answer key included or excluded depending on the switch.
  4. Diagnose, then drill. If the Gate 3 mirror goes badly, the problem is mechanics — live in the reference drills until they are automatic. If it goes well, go straight to the full practice exam for the interpretation questions.
