Gate 3 Mirror

The graded gate, same seven questions, same order, new numbers

Gate 3 is the only graded work this block, and it is the single best predictor of WPR 2. This page rebuilds it exactly: the same seven questions in the same order, carrying the same point values, with every number changed. Work it closed-book, then check.

What Gate 3 actually was: 25 points, seven questions, 100% computation — no caption, no interpretation item, nothing to write a paragraph about. That is a hard break from Gates 1 and 2, and it matches the course director's warning that WPR 2 is much more computational.

Total points
25
Format
Gate 3, exact
Authorized
Calculator only
  1. Show all work. Every Gate 3 rubric awards partial credit for shown work and deducts for a correct answer with none.
  2. Exact values where asked. Gate 3 said "no decimals" on the magnitude and "exact values" on the unit vector. Leave √29 as √29 and 4/5 as 4/5.
  3. The angle question wants degrees, rounded to two decimals. Check your calculator is not in radians.
  4. On row reduction you must show the Row Echelon Form and state the solution type. REF is enough — the gate did not require RREF.
Part 1 · Vectors · 13 points

Vectors

Use these vectors for problems 1–3.

u⃗ = ⟨−8, 15⟩      v⃗ = ⟨2, 1⟩
1.
Magnitude. Calculate |u⃗|. Show all work. Write the exact value in the box below (no decimals).
3 pts
|u⃗| =

Answer & scoring

|u⃗| = √((−8)2 + 152) = √(64 + 225) = √289 = 17

Squaring kills the minus sign — (−8)2 = +64, not −64. That single slip turns 289 into 161 and the answer into √161.

Gate 3 rubric: 3 pts correct with work shown · 2 pts correct with no work or a minor arithmetic error · 1 pt major error · 0 blank.
2.
Unit vector. Find the unit vector û in the direction of u⃗. Write exact values in the box below.

Answer & scoring

û = u⃗|u⃗| = ⟨−8, 15⟩17 = ⟨−8/17, 15/17⟩

Divide every component by the magnitude. Leave it as fractions — the gate asked for exact values, so ⟨−0.47, 0.88⟩ is not the answer it wants.

3.
Dot product. Compute u⃗ · v⃗. Show all work.
3 pts
u⃗ · v⃗ =

Answer & scoring

u⃗ · v⃗ = (−8)(2) + (15)(1) = −16 + 15 = −1

A scalar, not a vector. The negative sign is real and means the angle between them is obtuse — just barely.

Gate 3 rubric: 3 pts correct · 2 pts minor arithmetic error or correct with no work shown · 1 pt major error · 0 blank.
4.
Angle between vectors. Given the information below, find the angle θ between w⃗ and z⃗ in degrees. Round to two decimal places. Show all work.
4 pts
w⃗ = ⟨1, 2, 2⟩     z⃗ = ⟨6, 3, −2⟩ w⃗ · z⃗ = 8 |w⃗| = 3 |z⃗| = 7 cos(θ) = w⃗ · z⃗|w⃗||z⃗|
θ ≈          degrees

Answer & scoring

cos θ = 8 / (3 × 7) = 8/21 = 0.3810

θ = cos−1(0.3810) = 67.61°

Note the gate hands you the dot product and both magnitudes. The only work being tested is dividing and taking the inverse cosine — so there is no excuse for losing these four points.

Gate 3 rubric: 4 pts correct · 3 pts minor arithmetic, a rounding error, computing in radians, or correct with no work · 2 pts major error, explicitly including "calculates cosine similarity instead of angle" · 1 pt some work of value · 0 blank.
The named trapStopping at 0.3810 and calling it the answer is the error the graders wrote into the rubric. cos θ is the cosine similarity; θ is the angle. If the question says "in degrees," you are not done until you press cos−1.
Part 2 · Matrices · 12 points

Matrices

Use the following matrices for problems 5–6.

A = [  2  −1 ]
[  3    5 ]		 B = [ 4    0 ]
[ 1  −2 ]
5.
Matrix multiplication. Compute AB. Show all work.
4 pts
AB =

Answer & scoring

Each entry is a row of A dotted with a column of B:

(1,1): 2(4) + (−1)(1) = 8 − 1 = 7
(1,2): 2(0) + (−1)(−2) = 0 + 2 = 2
(2,1): 3(4) + 5(1) = 12 + 5 = 17
(2,2): 3(0) + 5(−2) = 0 − 10 = −10

AB = [ 7  2 ; 17  −10 ]

Two sign traps live in this one: (−1)(−2) = +2, and 5(−2) = −10.

Gate 3 rubric: 4 pts correct · 3 pts minor arithmetic error or correct with no work · 2 pts major error · 1 pt some work of value · 0 blank.
6.
Determinant & inverse. Calculate det(A) and state whether A−1 exists. Show all work.
4 pts
det(A) =              Does A−1 exist?

Answer & scoring

det(A) = (2)(5) − (−1)(3) = 10 − (−3) = 10 + 3 = 13

13 ≠ 0, so yes, A−1 exists.

The subtraction of a negative is the whole difficulty. A cadet who writes 10 − 3 = 7 has the right formula and the wrong sign.

Answer both halves. Gate 3's rubric drops you from 4 to 2 if the determinant is right but the existence conclusion does not follow.

Gate 3 rubric: 4 pts correct · 3 pts minor arithmetic error, existence follows · 2 pts determinant correct but existence does not follow · 1 pt some work · 0 blank.
7.
Row reduction. Use row reduction to solve the system below. State whether the solution is unique, none, or infinitely many, and give the solution if it exists. You must show all work and the Row Echelon Form of the augmented matrix.
4 pts
2x1 + 3x2 = 8       x1 − x2 = 1
Solution type:
x1 =              x2 =

Answer & scoring

Augmented matrix:  [ 2   3 | 8 ; 1  −1 | 1 ]

R2 ← 2R2 − R1:  [ 2   3 |   8 ; 0  −5 | −6 ]  ← this is a Row Echelon Form

Row 2: −5x2 = −6, so x2 = 6/5

Row 1: 2x1 + 3(6/5) = 8 → 2x1 = 8 − 18/5 = 22/5 → x1 = 11/5

Solution type: unique — every column has a pivot and there is no contradictory row.

Check: 2(11/5) + 3(6/5) = 22/5 + 18/5 = 40/5 = 8 ✓ and 11/5 − 6/5 = 5/5 = 1 ✓

Expect fractions. The real Gate 3 answers were 7/3 and 4/3. If your answer comes out ugly, that is not evidence you made a mistake — check it by substitution and move on. 11/5 = 2.2 and 6/5 = 1.2 are both acceptable forms.

Gate 3 rubric: 4 pts correct — note the grader's own remark that the solution is unique but the REF is not, so any valid sequence of row operations is accepted and RREF is not required · 3 pts minor arithmetic error, solution type follows · 2 pts solving by a method other than row reduction · 1 pt no work of value · 0 blank.
Watch forSolving by substitution and writing down the right answer. The gate explicitly docks that to 2 of 4 — the method is what is being graded, and the REF must appear on the page.

Four things this changes

1 — Zero interpretationNot one question asked for a sentence. Gates 1 and 2 put 10 of 25 points on a caption; Gate 3 put none. Drill arithmetic tonight, not prose.
2 — Unit vectors are on the testThey carried 3 of 25 points and appear nowhere in HW3's Section 1 problem list. Divide every component by the magnitude; verify the result has length 1.
3 — Angle, not cosine similarityThe rubric names this as a major error worth 2 of 4. cos θ is an intermediate value. The answer is θ, in degrees.
4 — Exact values and fractions"No decimals" on the magnitude, "exact values" on the unit vector, and a row-reduction answer of 7/3 and 4/3. Get comfortable leaving answers as radicals and fractions.
